# Accessibility

- Use semantic HTML elements and correct heading order.
- Associate every form control with a visible or programmatic label.
- Ensure all actions work with a keyboard and have visible focus states.
- Use buttons for actions and links for navigation.
- Provide accessible names for icon-only controls.
- Do not communicate status or errors using color alone.
- Maintain sufficient text and control contrast.
- Manage focus correctly in dialogs and menus; support Escape where appropriate.
- Use ARIA only when native HTML semantics are insufficient.
