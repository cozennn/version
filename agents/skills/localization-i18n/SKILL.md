# Localization and Internationalization

- Preserve the project's existing translation architecture and locale keys.
- Keep Arabic layouts right-to-left and English/French layouts left-to-right.
- Check alignment, icons, navigation order, forms, tables, and mixed-direction text in RTL.
- Avoid hard-coded user-facing strings when the project uses translation files.
- Translate meaning naturally; do not use literal machine-like phrasing.
- Keep dates, numbers, currencies, and labels consistent with the selected locale.
- Ensure language switching updates the whole relevant interface without losing user input.
