# Responsive Design

- Inspect existing breakpoints and responsive utilities before adding new ones.
- Design mobile-first where practical, then enhance for wider screens.
- Prevent horizontal overflow, clipped controls, and unreadably narrow content.
- Keep navigation, dialogs, tables, forms, and ticket views usable on touch screens.
- Use flexible grids, sensible max-widths, and content-driven sizing.
- Ensure buttons and interactive targets are comfortably tappable.
- Test at narrow mobile, tablet, and desktop widths using available project tooling.
- Do not hide important actions on mobile without providing an accessible alternative.
