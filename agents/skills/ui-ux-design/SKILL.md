# UI/UX Design

- Inspect the existing page and shared design system before changing anything.
- Preserve NorDa's established visual identity; do not introduce a new palette or typography without a clear reason.
- Aim for mature, professional, calm interfaces. Avoid generic template aesthetics, childish decoration, unnecessary gradients, emoji, fake metrics, and oversized rounded cards.
- Establish clear hierarchy, consistent spacing, readable typography, restrained borders, and purposeful whitespace.
- Reuse existing components and tokens. Do not duplicate components that already exist.
- Keep public-site and admin experiences visually related while respecting their different jobs.
- Every visible control must have a clear purpose and a working interaction.
- Check empty, loading, success, and error states where relevant.
- Before finishing, summarize the exact files changed and any remaining visual issues.
