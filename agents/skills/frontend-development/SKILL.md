# Frontend Development

- Read the existing project structure, package scripts, and nearby components before editing.
- Follow the repository's existing framework, conventions, naming, and dependency choices.
- Prefer small, focused changes over broad rewrites.
- Reuse existing components, hooks, utilities, and API clients.
- Keep components understandable; separate reusable logic when it improves clarity.
- Handle loading, empty, error, and success states explicitly.
- Validate user input at the UI boundary, but enforce security and business rules on the server too.
- Do not add dependencies unless they solve a real need; explain why when adding one.
- Run the narrowest relevant check/build after edits and report its actual result.
